# Architecture icon sources and use

The SVG files in this folder are unmodified official provider assets used only to illustrate services in the two architecture diagrams.

- AWS assets: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/), package release 2026-07-31.
- Azure assets: [Azure Architecture Icons](https://learn.microsoft.com/en-us/azure/architecture/icons/), Azure Public Service Icons V24.
- Microsoft Entra ID asset: [Microsoft Entra architecture icons](https://learn.microsoft.com/en-us/entra/architecture/architecture-icons), October 2023 package.

The provider guidance permits these icons in architecture diagrams and documentation. Icons have not been cropped, recoloured, flipped, rotated, or distorted. Only filenames and storage locations were normalized. Product names appear beside the icons. See `manifest.json` for each original archive path, source URL, release label, local path, and SHA-256 checksum.
